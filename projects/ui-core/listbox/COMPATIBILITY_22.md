# NeuListbox — external compatibility record

Baseline: the published reference Listbox declaration, implementation, and current official Listbox documentation. Neural keeps its existing `selectionChange: T[]` contract and uses typed Neural APIs where copying vendor-specific configuration objects would leak framework internals.

## O1 additive bridge

Angular package secondary entry points cannot compile a direct source import from a sibling secondary entry point. O2 therefore adds only `ɵ`-prefixed re-exports for the existing O1 internal row/filter/navigation/lazy helpers. They are explicitly framework-internal and are not supported consumer APIs; no O1 algorithm was redesigned or duplicated.
