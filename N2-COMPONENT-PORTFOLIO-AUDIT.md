## Method and taxonomy

Source public_api.ts exports were resolved with TypeScript's checker to distinct @Component class declarations and cross-checked against the checked-in public-contract.v2.json (94/94). There are **97 public entrypoints** including root, **96** secondary source entrypoints, **82** component-bearing secondary entrypoints and **14** non-component secondary entrypoints. Of those 14, nine are directive-oriented (animate-on-scroll, context-menu, drag-drop, focus-trap, image-viewer, key-filter, popover, ripple, tooltip), one service-oriented (url-state), and four utility/foundation/testing/internal. Root is separate. The contract independently classifies 121 public directives and 11 services; neither is counted as a component. dist, tests, fixtures, private renderer classes and Showcase are excluded.

## Reconciliation of the historical “98”

N2-PHASE-2 used **98 canonical component source files** before removing Chart; this is a file count, not the number of public @Component declarations. The historical public contract at fbe9e5c^ records **102** exported components. The identity delta is exact: removed `./chart#NeuChartComponent`, `./date-input#NeuDateInputComponent`, `./icon#NeuIconComponent`, `./image-gallery#NeuImageGalleryComponent`, `./inline-editor#NeuInlineEditorComponent`, `./multiselect#NeuMultiselectComponent`, `./organization-chart#NeuOrganizationChartComponent`, `./scheduler-gantt#NeuSchedulerGanttComponent`, `./table-core#NeuTableCoreComponent`, `./tags#NeuTagsComponent`; added `./date-input#NeuDateInputControl`, `./inline-editor#NeuInlineEditorControl`. Thus **102 − 10 + 2 = 94** current public component identities. Chart and TableCore disappeared; Multiselect merged into Select and Tags into InputTags; DateInput and InlineEditor changed class identities to their single Forms controls; Table 1.x and TreeTable 1.x were replaced while retaining their public component symbols. The current 94 is source-derived after 2 D1 physical removals, not an adjusted historical file count.

## Product decisions and evidence standard

Calendar and Timeline are KEEP; Calendar's N2-022 event contract is completed, Timeline remains pending visual/semantic certification. OrganizationChart and the sole SchedulerGantt component were physically removed in D1, not modernized or retained as current components. There is **no separate public Gantt or Scheduler component/entrypoint**; both concepts reside in the one SchedulerGantt runtime, so removal counts once. Generic Charts already left Core and future neural-charts is not an active Core component. N2-023's visual-axis edits alone never certify a component: rows marked “transverse only” remain pending. The 24 Signal Forms controls are migration evidence; B7 certified Slider/Rating P2 and B8 certified InputMask P2. B9 certifies Splitter controlled resizing and ScrollArea logical scrolling; collapse/restore is deferred P3. B5 certifies the controlled Compare family and presentation-only children. A1 certifies Button, ButtonGroup, presentational Tag, and Toolbar; removal belongs to Chip. Completed rows require the named component report/contract gate, not a passing incidental test.
