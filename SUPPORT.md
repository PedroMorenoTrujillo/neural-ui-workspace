# Support and compatibility

## Supported Angular versions

Neural UI 1.12.x supports Angular and Angular CDK `>=19.0.0 <23.0.0`. The release gate compiles packed consumer applications on Angular 19, 20, 21 and 22. A passing build is compatibility evidence, not a promise that upstream Angular bugs can be fixed inside Neural UI.

Keep all `@angular/*` packages and `@angular/cdk` on compatible minors. See the root README for known upstream workarounds.

## Neural UI release support

The latest published release is the supported line for fixes and security updates. Upgrade guidance is maintained in [MIGRATIONS.md](./MIGRATIONS.md) and release changes in [CHANGELOG.md](./CHANGELOG.md). Older releases remain available under MIT but do not receive a guaranteed maintenance window.

## Getting help

Search existing documentation and issues, then open a minimal reproducible issue using the repository templates. Public support is best effort and has no guaranteed response time. Use the private process in [SECURITY.md](./SECURITY.md) for vulnerabilities.

Paid support, paid browser farms, paid assistive technology and external certification are not required by the project. JAWS is not part of the validated assistive-technology matrix because it is paid.
